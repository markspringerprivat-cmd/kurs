# Rollenkarten-Webseite

Statische Webseite für GitHub Pages.

## Dateien

Alle Dateien liegen bewusst auf einer Ebene:

- `index.html` – Startseite mit Namensliste und zufälliger Rollenverteilung
- `script.js` – Logik für Namen und Zufallsverteilung
- `style.css` – Gestaltung der gesamten Webseite
- `schueler.html` – Rollenkarte Schüler/in
- `lehrkraft.html` – Rollenkarte Lehrkraft
- `beobachter.html` – Rollenkarte Beobachter/in

## GitHub Pages

1. Repository öffnen.
2. Alle Dateien aus diesem Ordner direkt in das Repository hochladen.
3. Unter **Settings → Pages** als Source `Deploy from a branch` auswählen.
4. Branch `main` und Ordner `/root` auswählen.
5. Speichern.

Wichtig: `index.html` muss direkt auf oberster Repository-Ebene liegen.
