# Rollenverteilung und Rollenkarten

Statische Website für GitHub Pages.

## Dateien

Alle Dateien müssen direkt auf oberster Ebene des Repositories liegen:

- `index.html`
- `rollenverteilung.html`
- `rollenkarten.html`
- `schueler.html`
- `lehrkraft.html`
- `beobachter.html`
- `reflexion.html`
- `style.css`
- `script.js`

Die Website speichert Eingaben lokal im Browser und kann über den Button „Webseite zurücksetzen“ geleert werden.
